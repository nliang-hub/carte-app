# Image Assets

## Dishes
Place dish images in this folder with descriptive names:
- spaghetti-carbonara.jpg
- margherita-pizza.jpg
- caesar-salad.jpg
- etc.

## Usage in Code
Reference images with absolute paths from root:
```javascript
imageUrl: "/images/dishes/spaghetti-carbonara.jpg"
```

## Image Guidelines
- Use web-optimized formats (JPG, PNG, WebP)
- Recommended size: 800x600px or similar aspect ratio
- Keep file sizes under 500KB for good performance
- Use descriptive filenames (kebab-case recommended)
